# Blog structures

Choose the form that serves the reader's question and the available evidence.
These are possible orders, not required sections. Keep each point as a heading
or bullet note until the author requests prose.

| Form | Possible order | Check before choosing |
|---|---|---|
| Argument | Claim → context → evidence → objections → qualified conclusion | Does the evidence support the claim's scope? |
| Tutorial | Outcome → prerequisites → steps → failure cases → next step | Can the reader perform and check each step? |
| Story | Situation → problem → action → result → consequence | Which events and results are confirmed by the author? |
| Comparison | Decision → criteria → alternatives → tradeoffs → recommendation | Are the criteria consistent across alternatives? |
| List | Shared question → parallel items → connecting conclusion | Do the items answer the same question? |
| Explanation | Reader's question → required concepts → mechanism → limits → implications | Does each concept arrive before it is needed? |

## Check the order

- State what each section adds that the previous one did not.
- Move background to the first place the reader needs it.
- Combine repeated arguments unless the later one adds evidence or a condition.
- Include the strongest relevant objection and the support needed to answer it.
- Compare the title and opening promise with the conclusion. Resolve differences
  in the outline before writing prose.

If the post has competing main points, ask which one it should support. Keep the
other material in notes or propose a separate post. A chronological list does not
prove a cause, and a story does not require a successful outcome.
